# Portfólio de Fabiano

Portfólio feito para a disciplina Interface Homem-Máquina do curso de Análise e Desenvolvimento de Sistemas do IF Baiano, Campus Guanambi (turma 2ADS).

Site: https://fabianocba.github.io

## Seções

Início, Sobre mim, Habilidades, Projetos e Contato.

## Tecnologias

- HTML5 semântico
- CSS3: variáveis, Flexbox, Grid, `clamp()`, `:has()`, `:user-invalid`, `@keyframes`, `@property`, contadores e `animation-timeline`
- JavaScript para salvar o tema, fechar o menu no celular e atualizar o ano do rodapé

## Estrutura

```
portfolio/

```

## Como executar

Abra o `index.html` no navegador.
